# Recuperación

Si una importación falla, la colección confirmada permanece intacta. Exporta un respaldo antes de operaciones grandes. Ante cuota o almacenamiento no disponible, libera espacio, usa otro perfil o reduce el archivo. Si el navegador borró IndexedDB, restaura mediante un JSON válido. El deshacer de eliminación no sobrevive cierre o suspensión.
