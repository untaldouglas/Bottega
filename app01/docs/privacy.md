# Privacidad

Los datos se guardan exclusivamente en IndexedDB del navegador. No se envían a servidores, no hay cuentas, cookies de aplicación, telemetría ni analytics. La exportación contiene solo el esquema, fecha y colección. Cualquier persona con acceso al perfil del navegador puede leerla; no se ofrece cifrado.

Hallmark v2 no añade proveedores LLM, fallback, endpoints ni integraciones. El expediente de fabricación se conserva fuera de este repositorio y no se incluye en el runtime.
