# Glosario

Registro canónico: [`docs/glossary/terms.yaml`](docs/glossary/terms.yaml). Este archivo se genera desde el registro para que los agentes lean el lenguaje del dominio; edita el registro y ejecuta `make docs`, no este archivo.

## Backlog

- **Aliases:** lista de trabajo
- **Definición:** Lista priorizada de trabajo pendiente, con contexto suficiente para decidir su ejecución.

Detalle: [`docs/glossary/entries/backlog.md`](docs/glossary/entries/backlog.md#glossary-backlog)

## Baseline

- **Aliases:** línea base
- **Definición:** Estado de referencia documentado contra el cual se comparan cambios posteriores.

Detalle: [`docs/glossary/entries/baseline.md`](docs/glossary/entries/baseline.md#glossary-baseline)

## Criterio de aceptación

- **Aliases:** criterios de aceptación
- **Definición:** Condición verificable que una entrega debe cumplir para ser aceptada.

Detalle: [`docs/glossary/entries/acceptance-criteria.md`](docs/glossary/entries/acceptance-criteria.md#glossary-acceptance-criteria)

## Definition of Done

- **Aliases:** DoD; definición de terminado
- **Acrónimo:** DOD
- **Definición:** Criterio verificable que debe cumplirse antes de declarar terminada una entrega.

Detalle: [`docs/glossary/entries/definition-of-done.md`](docs/glossary/entries/definition-of-done.md#glossary-definition-of-done)

## Evidencia

- **Aliases:** evidencias; evidence
- **Definición:** Salida reproducible que demuestra el resultado de una acción, prueba o decisión.

Detalle: [`docs/glossary/entries/evidence.md`](docs/glossary/entries/evidence.md#glossary-evidence)

## Gate

- **Aliases:** puerta de calidad
- **Definición:** Punto de control con criterios explícitos que autoriza avanzar o exige corrección.

Detalle: [`docs/glossary/entries/gate.md`](docs/glossary/entries/gate.md#glossary-gate)

## Kanban

- **Aliases:** tablero Kanban
- **Definición:** Sistema visual para gestionar trabajo mediante estados, límites y flujo explícito.

Detalle: [`docs/glossary/entries/kanban.md`](docs/glossary/entries/kanban.md#glossary-kanban)

## Migración

- **Aliases:** migración incremental
- **Definición:** Cambio controlado desde una estructura o estado anterior hacia otro nuevo.

Detalle: [`docs/glossary/entries/migration.md`](docs/glossary/entries/migration.md#glossary-migration)

## Paquete de revisión

- **Aliases:** review packet
- **Definición:** Resumen mínimo de un cambio con Summary, Evidence y Merge Danger que alimenta la revisión independiente y el cuerpo de una solicitud de cambios.

Detalle: [`docs/glossary/entries/review-packet.md`](docs/glossary/entries/review-packet.md#glossary-review-packet)

## Propietario

- **Aliases:** owner; responsable
- **Definición:** Rol o equipo responsable de mantener una definición, decisión o entregable.

Detalle: [`docs/glossary/entries/owner.md`](docs/glossary/entries/owner.md#glossary-owner)

## Release

- **Aliases:** versión publicada
- **Definición:** Versión identificable de un producto preparada para distribución según sus controles.

Detalle: [`docs/glossary/entries/release.md`](docs/glossary/entries/release.md#glossary-release)

## Retrospectiva

- **Aliases:** retro
- **Definición:** Práctica posterior al cierre que revisa sesiones reales para proponer mejoras al entorno del agente, sin emitir veredicto sobre el producto.

Detalle: [`docs/glossary/entries/retrospective.md`](docs/glossary/entries/retrospective.md#glossary-retrospective)

## Revisión

- **Aliases:** revisión editorial
- **Definición:** Evaluación independiente de contenido o cambios frente a criterios acordados.

Detalle: [`docs/glossary/entries/review.md`](docs/glossary/entries/review.md#glossary-review)

## Rollout

- **Aliases:** despliegue gradual
- **Definición:** Introducción controlada de un cambio a sus usuarios o entornos objetivo.

Detalle: [`docs/glossary/entries/rollout.md`](docs/glossary/entries/rollout.md#glossary-rollout)

## Skill

- **Aliases:** habilidad reutilizable
- **Definición:** Conjunto versionado de instrucciones y referencias reutilizables para una capacidad específica.

Detalle: [`docs/glossary/entries/skill.md`](docs/glossary/entries/skill.md#glossary-skill)
