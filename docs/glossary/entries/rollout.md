# Rollout

**Aliases:** despliegue gradual
**Categoría:** operación
**Propietario:** dsi-documentation
**Revisión:** 2026-10-15 (próxima: 2027-01-10)

Introducción controlada de un cambio a sus usuarios o entornos objetivo.

**Contexto:** Puede ser gradual y requiere criterios observables de éxito y reversión.
